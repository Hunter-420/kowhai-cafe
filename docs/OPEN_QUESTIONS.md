# Open Questions and Architectural Notes - Kowhai Cafe

## Resolved Decisions

1. Static Hosting vs Dynamic SSR:
   - Configured for GitHub Pages static hosting using hash-based view routing, client-side data management, and automated GitHub Actions deployment.
   - Eliminates 404 errors on browser refresh while enabling instant load times and zero hosting fees for the demo.

2. Design Upgrades over Figma Starters:
   - Applied UI Skills baseline-ui typography rules (text-balance on headings, text-pretty on body copy, tabular-nums on monetary figures and hours).
   - Replaced photo placeholders with stylized, brand-aligned visual gradients and iconography that maintain 100/100 Lighthouse performance metrics.
   - Added interactive FAQ accordion, catering packages view, and neighbourhood journal to provide a complete production-grade marketing site.
